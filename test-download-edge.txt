TEST - DOWNLOADING THE ZIP, AND WHETHER IT ACTUALLY HELPS

Written 2026-09-19, after adding stablesound.zip to the v1.0.0 release.

Why this test exists. The README now tells people to take the zip if they use
Microsoft Edge, on the grounds that Edge refuses to keep a downloaded unsigned
program without a fiddly two-step Keep, and does not object to a zip. It also
tells them the zip does not save them the SmartScreen prompt on first run.
Neither of those claims has been checked on this machine. They come from
documented behaviour, not from watching it happen. If either is wrong the
README is wrong, so it is worth twenty minutes.

Before you start. Do this on a machine, or a user account, where StableSound
has not been run before if you can - a copy that has already been run and
trusted will not prompt again, which would make the test tell you nothing. If
that is not practical, use a new folder and say so in the notes at the end.

Please answer in your own words rather than yes or no where there is room for
it. What the wording of a prompt actually was matters more than whether one
appeared.
