WHAT CHANGED
------------

1. The trackpad. Your log answered it. Three lines in a row, as you
   swept:

       input seen, no mouse activity ever recorded -> keyboard
       woken by keyboard input
       input seen, mouse active 0 ms before it -> mouse

   Watching the mouse was right all along, and it was working - 42
   events in your session were correctly put down to the mouse. The
   fault was a race. Windows notes the time of your input the instant
   your finger lands, but the mouse's own report has to be delivered to
   the app afterwards. The app looked in the gap between the two, found
   no mouse activity yet, and called it typing. Only the very first
   event of a sweep can lose that race - and the first is the one that
   wakes it.

   So an input that nothing has claimed is now held for a quarter of a
   second and judged when the wait is up, by which time the mouse has
   spoken. The quarter second is measured from your log, not guessed:
   in both of your accidental wakes the mouse reported itself in under
   a tenth of a second.

   The cost is that the keyboard now wakes keep-alive a quarter of a
   second later than it did. That should be invisible, because waking
   from a release means reconnecting Bluetooth anyway, which takes
   about three seconds. Test 27 asks whether you notice.

2. The settings dialog. Real Windows controls, not drawn ones -
   combo boxes, edit fields, checkboxes, OK and Cancel, the same kinds
   of control any Windows dialog has. Three ways to open it:

       - the tray menu, "Settings..."
       - Ctrl+Win+F11, from anywhere
       - typing: settings

3. The hotkeys are typed in as text, like "ctrl+win+f12", rather than
   recorded by pressing them. I think typing is better for you - you
   can read back what is there and correct one character - but tell me
   if you would rather press the combination.

4. There is now a second hotkey, Ctrl+Win+F11, which opens the
   settings. Every global hotkey is one taken away from every other
   program, so say if you would rather not have it.

5. "Start StableSound when I sign in" is in the dialog.
