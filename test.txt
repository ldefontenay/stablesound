HOW TO USE THIS FILE
--------------------

Each test has one or more lines beginning with "ANSWER:".
Type your notes after the colon. Free text is fine - there is no
format to follow, and short is fine.

If something unexpected happens, use the "ANYTHING ODD:" line in that
section. Those are often the most useful notes, so please do not skip
them if something felt off.

If a test cannot be run, write why on the ANSWER line rather than
leaving it blank. "Could not tell" and "not sure" are useful answers.

Nothing here has been tried on the AeroClip. Every tone, every timing
and the hotkey itself is a guess until you run it.


WHAT IS NEW SINCE LAST TIME
---------------------------

Three things, and one correction you asked for.

1. A global hotkey: Ctrl+Windows+F12 toggles keep-alive from anywhere.
2. Earcons: a short rising two-note tone when keep-alive comes on, and
   a falling one when it lets go. They play through the headphones
   being kept awake, so hearing one also proves the headset is up.
3. A tray icon with a menu.
4. Waking on input now ignores the mouse, as you asked. Keyboard only.

The console commands all still work, and there are some new ones.


BEFORE YOU START
----------------

Build and run from the repo root:

    cargo run

Have the AeroClips connected and set as the default output, and have
your iPhone nearby for the handover tests.

Type "help" at the prompt for the full command list. The new ones are:

    mouse on | mouse off      let the mouse wake it too (off by default)
    earcons on | earcons off  the state-change tones
    volume 0.2                how loud those tones are, 0.0 to 1.0
    hotkey ctrl+win+f12       change the combination

The startup banner should say "Hotkey: Ctrl+Win+F12 toggles keep-alive."

ANSWER - did it say that, or did it warn that it could not register the
hotkey?

TEST 13 - IS THE OFF-TONE HEARD BEFORE THE HEADSET LETS GO
===========================================================

This one matters most. The off-tone deliberately plays through the
stream that is about to close, because playing it afterwards would
reopen the device and take the headphones back off your phone a moment
after handing them over. So the release waits for the tone to finish.
The question is whether that actually works on the AeroClip.

Steps:

1. Press Ctrl+Windows+F12 to switch keep-alive on.
2. Wait a few seconds.
3. Press Ctrl+Windows+F12 to switch it off, and listen carefully.

ANSWER - did you hear the whole falling tone, both notes, or was it cut
off part way through?

4. Repeat that two or three more times.

ANSWER - was it the same every time, or did it sometimes get clipped?

5. Now with keep-alive off, start playing something on your iPhone.

ANSWER - did the phone take the headphones, and roughly how long did it
take?

ANSWER - did switching off feel slower than it used to? It now waits
about a third of a second for the tone. Noticeable, or not?

TEST 16 - MOUSE NO LONGER WAKES IT, KEYBOARD STILL DOES
===========================================================

This is the correction you asked for after the last round.

Steps:

1. Start the app and type: idle 10
   (a short timeout, so you are not waiting around)
2. Type: on
3. Say nothing and play nothing. Wait for the falling tone, about ten
   seconds. That is the automatic release.
4. Now move the trackpad - deliberately, a good sweep - but do not
   touch any key.

ANSWER - did keep-alive stay off? It should. Listen for a rising tone,
and check the log for "woken by keyboard input".

5. Wait a few seconds, still not touching the keyboard, and move the
   pointer again.

ANSWER - still off?

6. Now press a key.

ANSWER - did keep-alive come back on?

7. Type: mouse on
8. Type: off, wait for the release, then move the trackpad without
   touching a key.

ANSWER - with "mouse on", did the trackpad wake it this time?

9. Type: mouse off      (back to the default)

ANSWER - in real use, does keyboard-only waking do what you wanted?

TEST 18 - ONE KNOWN GAP, PLEASE CONFIRM IT IS HARMLESS
===========================================================

An earcon can only play through a stream that is already open. So if
keep-alive is already off and you press the hotkey to switch it off
again, there is nothing to play through and you hear nothing.

I think this is harmless, because if nothing is open the headphones are
not being held anyway - but it means the hotkey can sometimes appear to
do nothing.

Steps:

1. Make sure keep-alive is off (press the hotkey until you hear a
   falling tone, then wait a moment).
2. Press the hotkey twice in quick succession.

ANSWER - what did you hear? Anything confusing about it?

3. Disconnect the AeroClips entirely, then press the hotkey a couple of
   times.

ANSWER - anything confusing or alarming happen with no headphones
connected?
