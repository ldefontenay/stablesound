===========================================================
FOR REFERENCE - WHY THESE THREE TESTS
===========================================================

Test 1 checks the assumption the whole design rests on.
Test 2 decides how the auto-release timer knows you are still active.
Test 3 picks the keep-alive signal, and interacts with Test 2 - a
louder signal makes the detection in Test 2 harder.

If Test 3 concludes we need "sine", then Test 2's simple approach
will not work and we need a more complex one. That is fine, it just
needs to be known before building.

ANYTHING ODD:

TEST 9 - DOES WAKING ON INPUT FEEL RIGHT?
===========================================================

The rule to check: turning keep-alive off BY HAND should stay off
even if you type. But an automatic release should be undone by the
next keypress. The idea is that deliberately handing the headset to
your phone sticks, while merely pausing does not.

Steps:

2. Type: idle 30
3. Type: on

   its own.
