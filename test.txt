WHAT CHANGED, AND WHY
---------------------

1. The tray icon no longer says its state twice. You found it reading
   "StableSound: headphones free StableSound: headphones awake".

   That was Windows, not us, and worth knowing about because it will
   come up again. Windows 11 remembers whatever the tooltip said at the
   moment an icon is added, treats that as the icon's name for the rest
   of the session, and then reads out the name followed by the current
   tooltip - showing it once only while the two still match. So an icon
   added saying "headphones free" was always going to read as both the
   moment the state changed. Microsoft's own Windows Security icon does
   exactly the same thing on your machine: it reads "Windows Security -
   No actions needed. Windows Security - Actions recommended."

   The icon is now added as plain "StableSound" and the tooltip carries
   the state on its own, so it should read "StableSound Headphones
   awake". That is the same shape as the built-in icons - your volume
   icon reads "Volume Headphones (soundcore AeroClip): 44%". It is also
   shorter than what it replaced.

2. Punctuation keys work in hotkeys. You wanted ctrl+win+; and it was
   refused. There was no good reason for that.

   Which key types a semicolon depends on the keyboard layout, so the
   app now asks Windows rather than carrying a list of its own. Any
   single character works. Where a character needs Shift to type it, the
   Shift becomes part of the combination, because that is what your
   fingers do anyway - ask for ctrl+win+: and you will be told you have
   set Ctrl+Win+Shift+;, which is the same three keys. The plus key is
   the one exception and is written as the word "plus", since a plus
   sign is what separates the parts.

3. Messages are now in a window you can read back. Your words: "putting
   the information in a read-only edit field would solve this, by making
   it possible to use the cursor keys to review the text."

   That is what it is now - a read-only edit field, which the focus
   lands on when the window opens, so it should be read out just as the
   old message box was, and then the arrow keys will go back over it a
   line or a word at a time with no cursor mode to switch into. Enter or
   Escape closes it, and the focus still returns to the field that was
   wrong.

   Every message the settings dialog shows now works this way, not only
   the hotkey one. The system's warning ding still plays first, so you
   still hear that something was refused before anything is spoken.

4. Logging is off by default, as you asked.

   One consequence, and it falls on me rather than you: when logging is
   off there is no record of what happened, so every test script from
   now on has to ask you to switch it on first. This one does, in the
   step below. If you ever hit something odd outside a test round, the
   first thing worth doing is turning logging on before trying to
   reproduce it.

5. The settings hotkey is on by default, as you asked. Ctrl+Win+F11
   again, and the checkbox to switch it off is still there for once you
   have the settings the way you want them.
