BEFORE YOU START

Build the new version and run it:

    cargo build --release

Then run target\release\stablesound.exe

If a StableSound from an earlier session is still running, exit it first, or
the new one will tell you it is already running - which is Test 50, but let us
get there in order.

Logging is off by default now, so please turn it on before anything else, or
there will be nothing to read afterwards:

  1. Press Ctrl+Win+F11 to open the settings.
  2. Tick "Write a log file, so a problem can be looked into later".
  3. Tick "Detailed logging, for troubleshooting".
  4. Press Enter for OK.

Did that work, and did the dialog close?

Yes, it worked and the dialogue closed.
